Obsidian Sticky setup

Wi-Fi

2.4 GHz networks only. Leave the password blank to keep the saved one.

Speech to text

Any OpenAI-compatible transcription endpoint works: Groq, OpenAI, or a local Whisper server.

Cleanup with an LLM
Obsidian

Needs the Local REST API plugin with its HTTP server enabled (port 27123). Daily mode also needs the "Local REST API - Periodic Notes" plugin. {time} and {text} are replaced in the template.

Device

The heading on the device's info screen, and the name it gives your router, so you can often reach this page at http://thename/ instead of the IP address. Letters and digits become the hostname and everything else becomes a hyphen. The router only sees a new name after the device restarts. Leave it blank to go back to Obsidian Sticky.

Auto picks the largest size that shows the whole note at once. A note too long for one screen scrolls: swipe up and down on the device's screen.

Latin letters only; Chinese always uses the built-in Noto Sans TC. All five are baked to the same capital height, so switching changes the shapes and not the size or the number of lines that fit.

Stopping the radio saves battery, at the cost of a few seconds' reconnect before the first note. While it is off this settings page is unreachable; press any button on the device to bring the radio back.
